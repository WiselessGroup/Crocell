# Security

Found a way to make Crocell leak traffic, read someone's stored subscriptions, or get at the service from another local user? Please report it privately through [GitHub's form](https://github.com/WiselessGroup/Crocell/security/advisories/new), in English or Russian. If the form doesn't open for you, open an issue that only asks for a contact, with no details in it.

Tell me the version, the system, and how to reproduce it. Leave real subscription links and keys out.

Only the latest release gets fixes. This is a small project, so there's no bounty and no promised response time, but I read these first.

Problems with a provider's servers aren't in scope. Crocell doesn't run any.
